# Sprint 6 final requirements and evidence matrix

Date: 2026-10-15, America/New_York. Authority: corrected SRS/SDD, amended DBDS, realigned WP-6 §4.6 and Sprint 5 handoff; source hashes match Batch A. This matrix addresses the four approved REST capabilities and their inherited rules, not implementation of every functional requirement during Sprint 6. Team acceptance remains PENDING.

Evidence identifiers (fully qualified under `SyncBridge.Core.Tests`): **EQ** = `UiApiEquivalenceTests.PairedHttpWorkflows_HaveEquivalentManufacturingEvidence` (Development and Production); **SQL-EQ** = `RestSqlEquivalenceTests.PairedHttpWorkflows_PersistEquivalentEvidenceThroughActualSqlServer`; **READ** = `RestBoundaryRegressionTests.ContextReads_RespectBothAdaptersWithoutMutation` (both environments); **AUTH** = `BothAdapters_RejectForgedAuthorityOnEverySelectedMutation` (Supervisor, Quality, Administrator); **TOKEN** = `AntiforgeryAndRevocation_BlockBeforeMutationOnBothAdapters` (both environments); **OPTIONAL** = `OptionalDeviationActivity_RemainsNullThroughBothAdapters`. Batch A's 13 `RestApiTests` and all prior Domain/Application/Razor/SQL tests are also retained. Fresh outcomes and exact test catalogs are in Batch B evidence.

There is no REST material/equipment-verification, signature creation, quality disposition, resume, administration, generic state setter or reporting capability.
