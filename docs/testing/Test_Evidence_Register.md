## Future Task Evidence Rule

Every future implementation task must:

- append new evidence rows to this register;
- preserve all prior evidence;
- save task-specific raw test output under `artifacts/test-evidence/<sprint>/<task>/`;
- save both human-readable evidence and machine-readable test evidence when automated tests exist;
- never overwrite evidence from earlier tasks;
- distinguish planned tests from executed tests;
- record failures as failures rather than silently omitting them.
